# Модельная 2.4.0 — черновик новой версии

Дата: 9 октября 2026. Изменения подготовлены в ветке codex/version-2-4-draft. Публичный установщик 2.3.1 остаётся последним стабильным выпуском; этот черновик не публикует обновление автоматически.

## Настройки приложения и полный экран

Кнопка-шестерёнка **Настройки приложения** доступна в каталоге, конструкторе, HTML-редакторе и самостоятельном анализе. Здесь находятся тема, показ быстрого старта, навигация каталога, видимость и ширина боковых панелей, возврат исходных панелей, резервные копии, перенос старой библиотеки, проверка обновлений и справка. Изменения внешнего вида сохраняются сразу. Параметры опыта и свойства объектов остаются в редакторе конкретной модели.

В Windows дополнительно можно выключить **Проверять обновления при запуске**. Изменение действует со следующего запуска; ручная проверка остаётся доступной. Проверка не скачивает и не устанавливает программу без подтверждения.

Рядом с шестерёнкой — **Полноэкранный режим**. В отдельном приложении F11 переключает полный экран, Esc возвращает обычное окно. В браузере кнопка использует полноэкранный режим документа; Esc выходит из него. Полный экран не сохраняется между запусками. Режим **Показ на уроке** по-прежнему управляет составом интерфейса опыта отдельно от размера окна.

## Перенос прежней библиотеки

1. Закройте прежнюю Модельную и сохраните текущие изменения в новом приложении.
2. **Настройки приложения → Перенести старую библиотеку → Выбрать папку старой библиотеки**.
3. Выберите именно папку data с catalog.json и models. В браузерной версии используется выбор папки браузера.
4. Проверьте количество моделей, папок, исторических версий и строк анализа. При необходимости скачайте копию переносимой библиотеки.
5. Подтвердите замену текущей библиотеки и нажмите **Перенести**.

Исходная папка не изменяется. Прежняя текущая библиотека сохраняется рядом под именем library.before-… или data.before-…. Переносятся также архивные модели и история; отсутствие analysis.json в старой версии означает отсутствие сохранённого самостоятельного анализа. Браузерные несохранённые черновики в папке data не хранятся и этим переносом не извлекаются.

Файлы проверяются до записи. Смена текущей библиотеки после предпросмотра требует повторного выбора. В Windows чтение обнаруживает изменение исходных файлов и запрещает перенос ссылок вместо файлов/папок. Лимиты остаются прежними: 128 MiB, 500 моделей, 500 папок, 30 исторических версий модели.

## Анализ таблиц

Импорт принимает CSV/TSV, экспорт анализа JSON и обычные JSON-таблицы: массив объектов либо объект с columns и rows. Заголовки могут быть русскими; пустые значения/null остаются пропусками. Пример обычного JSON:

```json
[{"Время": 0, "Координата": 0}, {"Время": 1, "Координата": 2}]
```

Предпросмотр объясняет одну колонку при неверном разделителе, неверные числа, пропуски и отсутствие единиц. Есть подсказки для десятичной запятой и Windows-1251. Единицы задаются автором; автоматического перевода или проверки размерностей пока нет. Обычная JSON-таблица ограничена 5 MiB, 50 000 строками и 20 колонками; вложенные объекты не являются ячейками. Экспорт анализа JSON сохраняет прежний лимит 16 MiB и свои проверки схемы.

При открытии сохранённого самостоятельного анализа график и статистика пересчитываются автоматически по сохранённым настройкам. Сам пересчёт не помечает анализ изменённым и не сохраняет новые настройки вместо автора. Масштаб остаётся фиксированным, если область уже сохранена. Явные кнопки пересчёта, подбора области и сохранения доступны по-прежнему.

## Подготовить опыт для ученика

**Экспорт → Подготовить опыт для ученика** объясняет различия копии в каталоге, редактируемого JSON и готового HTML. Учитель получает короткую инструкцию к выбранному типовому опыту, может изменить её и скачивает один HTML с текущими параметрами.

Инструкция включается в файл и не меняет сохранённый проект. Сцену конструктора и HTML-модель файл показывает в изолированном вложенном окне; сервер, приложение и интернет ученику не нужны. В готовом файле есть инструкция и кнопка полного экрана. Ответы ученик записывает отдельно. Обычный экспорт HTML без этого оформления остаётся доступным.

## Дополнения к черновику

- **О приложении** в настройках: фактический номер версии Windows-приложения, отметка черновика, встроенное руководство и список изменений. Документация открывается без интернета.
- **Понятные имена файлов:** название таблицы в экспортах CSV, анализа JSON и отчёта HTML; дата и время до миллисекунд в имени резервной копии. Имена учитывают ограничения Windows.
- **Предпросмотр HTML для ученика:** можно проверить инструкцию и управление перед скачиванием. Скачивание использует тот же подготовленный HTML; изменение текста требует обновить предпросмотр. Предпросмотр изолирован, включая вложенный опыт.
- **Ошибки в окне:** сообщение об ошибке отправки формы остаётся видимым до повторной попытки; текст ошибки отображается безопасно. Закрытие окна убирает сообщение.
- **Горячие клавиши** перечислены в настройках; поясняется отличие отмены текста от отмены изменения модели.
- **Показать в папке** в Windows появляется после завершённого сохранения экспорта. Программа выбирает сохранённый файл в проводнике. Для отменённого сохранения кнопка не появляется; перемещённый или удалённый файл вызывает понятную ошибку. Уведомление можно закрыть.

## Проверки

Локально: 167 Node-тестов без ошибок, галерея 20 моделей и 24 700 расчётных шагов без ошибок; 14 сценариев Chromium, включая настройки, выбор папки, JSON, пересчёт и оба вида учебного HTML. Desktop-сценарии проверяют F11/Esc, повторное открытие, настройки, нативный выбор старой папки, перенос истории/анализа, показ экспортированного файла в папке и отказ для запросов из окна руководства. Проверка закрытия воспроизводит уничтожение окна до удаления обработчика скачивания. Установочная проверка запускается на одноразовом Windows CI runner; локально она не изменяет регистрацию приложения.

Перед выпуском нужно оценить фактический CI черновика, включая упакованное приложение, обновление и установку. Пользовательские библиотеки и тестовые профили не входят в Git и сборку. Нового стабильного тега в рамках подготовки черновика нет.
