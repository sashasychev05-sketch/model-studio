# Изменения для следующего выпуска

Черновик в ветке codex/student-html-cleanup. Эти изменения пока не входят в опубликованную Модельную 2.4.1. Новый номер версии будет выбран после накопления достаточного набора обновлений.

- В экспортируемом HTML убраны поле «Ответ ученика» и блок «Предсказать → проверить → объяснить» с кнопками этапов. Это относится и к обычной HTML-демонстрации, и к HTML для ученика.
- Сохранены сценарии настройки опыта, интерактивная модель и инструкция учителя. Настройки задания в проекте и интерфейсе редактора сохраняются.
- В конструкторе добавлены «Показывать на сцене» и «Запретить перетаскивание». Скрытый объект остаётся в списке и расчёте, его связи и создаваемые поля работают; блокировка не меняет способ движения и позволяет править координаты через свойства.
- Динамические подписи показывают результат формулы рядом с объектом или вместо текста объекта «Подпись». Настраиваются текст перед значением, единица и точность от 0 до 8 знаков. Доступны время, параметры, координаты, скорости и вычисляемые величины.
- Переименование обновляет ссылки формул подписей; копия объекта получает собственные ссылки на его координаты. Видимость, блокировка и подписи сохраняются в JSON, истории и автономном HTML, поддерживают отмену и повтор правок.
- Изменение новых настроек отображения сохраняет время опыта. Ошибка подписи при выполнении показывает «—» и пояснение при наведении, не останавливая движение. Формулы выполняет существующий ограниченный обработчик без eval; единицы задаёт автор, автоматической проверки размерностей пока нет.
- Стрелка скорости не перехватывает перетаскивание тела. На узком экране управление воспроизведением переносится на следующую строку без горизонтальной прокрутки страницы.

Тег и новый публичный установщик не создаются. При будущей публикации существующие HTML нужно будет экспортировать заново.

## Создание математических моделей

- В окне новой модели разделены физическая модель, математическая плоскость, стартовый график функции и стартовая геометрическая конструкция. Все математические варианты доступны без написания HTML.
- Добавлены отрезок, вектор, окружность по центру и радиусу, многоугольник по вершинам и график y = f(x) на общей плоскости. Недостающие опорные точки создаются автоматически. В математической модели свойства обычных точек не перегружены массой и зарядом.
- Параметры формул управляются ползунками; размеры, периметр и площадь простого многоугольника обновляются при перемещении точек. Настраиваются цвет, толщина, заливка, видимость и подписи.
- Построения поддерживают JSON, историю, копирование, переименование, Undo/Redo, обычный HTML и HTML для ученика. Они доступны и в физических сценах, не добавляют сил и не меняют масштаб автоматически. Публичная галерея остаётся из 20 моделей.
- График функции — ограниченная численная отрисовка с разрывами на неопределённых участках и резких скачках; мелкие детали могут быть пропущены. Площадь корректна для простых многоугольников без самопересечений. Дуги, символьная алгебра, автоматические пересечения и общий решатель геометрии в эту задачу не входят.
