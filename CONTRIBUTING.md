# Участие в разработке Модельной

Предложения и ошибки принимаются через [Issues](https://github.com/sashasychev05-sketch/model-studio/issues/new/choose). Перед созданием проверьте, нет ли похожей задачи. Для ошибки приложите версию приложения, шаги воспроизведения, ожидаемый и фактический результат. Для новой возможности опишите конкретный опыт или задачу учителя.

Для изменения кода создайте отдельную ветку и pull request в main. Опишите, что изменилось, как проверить результат и какие проверки выполнены. Начните с [архитектуры и разработки](docs/DEVELOPMENT.md) и [правил проекта](AGENTS.md).

## Подготовка и проверки

Нужны Node.js 22.13+ и pnpm из package.json. Основной запуск доступен без установки пакетов: node server.mjs.

```sh
pnpm install --frozen-lockfile --ignore-scripts
node --test tools/*.test.mjs
node tools/check-gallery.mjs
pnpm exec playwright install chromium
pnpm test:browser
```

Для Windows-приложения установите Electron через node node_modules/electron/install.js и выполните pnpm test:desktop. Установочные тесты запускаются только на одноразовом CI runner.

Сохраняйте совместимость библиотек, автономный HTML и изоляцию моделей. Проверяйте численные допущения и фиксированный масштаб сцены. Не добавляйте в Git личную папку data/, рабочие профили, резервные копии или секреты.

Следующие направления описаны в [плане](docs/ROADMAP.md). Лицензии включённых сторонних библиотек сохраняются вместе с их файлами.
